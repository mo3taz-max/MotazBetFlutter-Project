# Motaz Bet Demo — Flutter

مشروع Flutter تجريبي بواجهة سوداء وذهبية، وصفحة طلب تجريبي ولوحة مسؤول محلية.

## البناء
1. فك ضغط الملف.
2. افتح مجلد `MotazBetFlutter` في بيئة Flutter التي تستخدمها.
3. تأكد أن `pubspec.yaml` موجود بجانب مجلد `lib`.
4. شغّل `flutter pub get`.
5. شغّل `flutter build apk`.

إذا فشل `Get dependencies`، افتح تفاصيل الخطوة وانسخ نص الخطأ؛ قد يكون السبب اتصال الإنترنت أو الوصول إلى pub.dev.

## ملاحظات
- لا ينفّذ أي مدفوعات ولا يتحقق من تحويلات.
- الطلبات محفوظة في الذاكرة فقط وتختفي عند إغلاق التطبيق.
- لا يوجد رفع صور ولا تسجيل دخول آمن للمسؤول.
- لا تستخدم بيانات مالية أو شخصية حقيقية في النسخة التجريبية.
